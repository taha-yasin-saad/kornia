`blur_pool2d`, `BlurPool2D` and `MaxBlurPool2D` now raise `ShapeError` for an input that is not `(B, C, H, W)`, as `max_blur_pool2d` and `edge_aware_blur_pool2d` already did. A `(C, H, W)` input used to fail inside `conv2d` with a message about the wrong dimension, or, when `C == H`, to run with `H` read as the channel count; that case now raises too. Add a batch dimension with `input[None]`.
